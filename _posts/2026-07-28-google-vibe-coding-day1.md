## Day 1 核心內容：Vibe Coding 與 Agentic Engineering

### 什麼是 Vibe Coding？

Vibe Coding 是一種全新的軟體開發模式，其核心概念是：

1. **人類描述意圖**：開發者用自然語言描述想要的功能
2. **AI 負責實現**：AI Agent 負責將意圖轉化為程式碼
3. **人類審核結果**：開發者審查並修正 AI 生成的程式碼

這種模式與傳統 coding 的最大差異在於，開發者不再需要手寫每一行程式碼，而是扮演「指揮者」的角色。

### 什麼是 Agentic Engineering？

Agentic Engineering（代理工程）是 Vibe Coding 的工程化框架，包含：

- **任務分解**：將複雜需求拆解為可執行的子任務
- **Agent 設計**：設計專門處理特定任務的 AI Agent
- **流程編排**：编排多個 Agent 協同工作
- **品質控制**：確保 AI 生成的程式碼符合標準

## 三種 AI 輔助開發模式

影片中提到了三種不同的 AI 輔助開發模式：

| 模式 | 說明 | 適用場景 |
|------|------|----------|
| **Copilot** | AI 建議程式碼片段，人類決定是否採用 | 熟悉程式碼的開發者 |
| **Autopilot** | AI 自動完成整個函數或模組 | 標準化、重複性高的工作 |
| **Vibe Coding** | AI 根據自然語言描述生成完整功能 | 快速原型開發、非技術人員 |

## 使用 Cursor 進行 Vibe Coding

### Cursor 是什麼？

Cursor 是一個基於 VS Code 的 AI 程式碼編輯器，專為 Vibe Coding 設計。它提供了：

- **自然語言程式碼生成**
- **上下文感知建議**
- **多檔案同時編輯**
- **程式碼解釋與重構**

### 實際操作流程

1. **打開專案**：將你的程式碼專案載入 Cursor
2. **描述需求**：在對話框中用自然語言描述你想做的事
3. **審查程式碼**：AI 生成程式碼後，仔細審查
4. **迭代修正**：根據需要不斷修正和改進

## 對開發者的意義

### 正面影響
1. **降低開發門檻**：非技術人員也能參與開發
2. **提高效率**：快速原型開發和迭代
3. **學習機會**：透過 AI 生成的程式碼學習新技術

### 挑戰
1. **品質控制**：需要更嚴格的審查流程
2. **技術理解**：仍然需要理解程式碼邏輯
3. **工具依賴**：對 AI 工具的依賴可能影響獨立開發能力

## 總結

Google 的這套課程代表了軟體開發的一個重要趨勢：**從手寫程式碼到指揮 AI 開發**。這並不意味著工程師的工作會被取代，而是會轉化為更高層次的「代理工程」角色。

掌握 Vibe Coding 和 Agentic Engineering 的概念，將是未來開發者的重要技能之一。
