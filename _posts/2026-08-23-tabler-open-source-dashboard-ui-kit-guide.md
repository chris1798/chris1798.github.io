# Tabler：41,000 Star 開源 Dashboard UI 套件完整功能說明

> **Tabler**（[github.com/tabler/tabler](https://github.com/tabler/tabler)）是一款超受歡迎的開源管理後台與儀表板 UI 套件，基於 **Bootstrap 5** 打造，提供超過 **77 個 UI 元件頁面**、內建圖表、圖示、郵件模板與豐富的 JavaScript 插件支援。僅需基本的 HTML 與 CSS 知識，即可快速構建專業級的後台介面。

### 為什麼選擇 Tabler？

Tabler 的定位非常明確：為所有想要快速建立管理介面的開發者提供一套 **預先構建好的元件庫**。它的任務是 delivering a user-friendly, clear and easy administration panel — 不論你是要做簡單的網站還是複雜的系統，都可以輕鬆上手。

唯一的要求是基本的 HTML 與 CSS 知識（外加一點 [Liquid](https://github.com/Shopify/liquid/wiki) 知識），你就能以最輕鬆的方式管理與視覺化各種資料！

## 🛠️ 本地開發

### 前置需求

- **Node.js** >= 18（建議 20+）
- **pnpm**（或使用 Corepack / npm 安裝）

### 快速開始

```sh
# 1. 複製專案
git clone https://github.com/tabler/tabler.git
cd tabler

# 2. 安裝依賴
pnpm install

# 3. 啟動開發環境
pnpm run start

# 4. 開啟瀏覽器
#   http://localhost:3000  → 預覽網站
#   http://localhost:3010  → 文件網站
```

### 一鍵建置

```sh
pnpm run build
# 開啟 http://localhost:3001 設定 Web 伺服器
```

### Docker 開發

**純 Docker 方式：**

```sh
# 1. 建立影像
docker build -t tabler .

# 2. 啟動容器（mount src 目錄以實時同步）
docker run -p 3000:3000 -p 3001:3001 -v $(pwd)/src:/app/src tabler
```

**Docker Compose 方式：**

```sh
docker compose build && docker compose up
```
