## 🎯 什麼是 Motrix？

### 一句話說明

> **Motrix = 整合多種下載協議 + Aria2 引擎 + 跨平台 + 開源免費的清爽下載器。**

它整合了**圖形界面**與 **Aria2** 的強大下載能力，讓你能在一個窗口裡管理所有下載任務。

### 為什麼選擇 Motrix？

相比 IDM（需付費）與其他下載器，Motrix 的特色：

| 特色 | 說明 |
|------|------|
| **開源免費** | MIT 授權，完全免費 |
| **無廣告** | 介面乾淨，不打擾 |
| **多協議** | HTTP / FTP / BT / 磁力 / 網盤 |
| **多執行緒** | Aria2 引擎，下載速度快 |
| **斷點續傳** | 中斷可繼續，不必重頭來 |
| **跨平台** | Windows / macOS / Linux 統一體驗 |
| **整合網盤** | 支援百度網盤下載 |

## 📥 安裝與設定

### 步驟 1：下載安裝

前往官方網站 [motrix.app](https://motrix.app) 或 GitHub，下載對應系統的安裝包：

| 平台 | 安裝方式 |
|------|---------|
| **Windows** | 下載 `.exe` 安裝檔 |
| **macOS** | 下載 `.dmg` 或 App Store |
| **Linux** | 下載 `.AppImage` / `.deb` / `.rpm` |

### 步驟 2：首次啟動

- 安裝完成後啟動 Motrix
- 預設會顯示空白任務列表

### 步驟 3：新增下載任務

在搜尋列貼上下載連結（HTTP / BT / 磁力），按 Enter 即可新增任務。

### 步驟 4：進階設定（推薦）

進入 **設定（Preferences）** → **進階設定**：

| 設定項 | 建議 |
|--------|------|
| **自動更新 Tracker** | ✅ 開啟（提升 BT 速度） |
| **多執行緒** | ✅ 開啟（加速下載） |
| **斷點續傳** | ✅ 開啟 |
| **下載限速** | 視需求設定 |
| **做種設定** | 視需求設定上傳比例 |
