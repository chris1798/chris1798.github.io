## 核心功能

### 1. 🍭 DeepDoc 深度文檔理解

RAGFlow 的 DeepDoc 模組提供業界領先的非結構化數據解析能力：

- **OCR 文字辨識**：從圖片和 PDF 中精確提取文字，支援多語言
- **版面分析（Layout Recognition）**：自動識別 10 種基本版面元件：
  - 文字區、標題、圖片、圖片說明、表格、表格說明、頁首、頁尾、參考文獻、公式
- **表格結構識別（TSR）**：識別列、行、列標題、投影行標題、跨欄儲存格等結構
- **表格自動旋轉**：掃描 PDF 中方向錯誤的表格，自動偵測最佳旋轉角度（0°/90°/180°/270°）
- **多模態解析**：使用多模態模型解析 PDF/DOCX 中的圖片，生成文字描述

| 文件類型 | 支援狀態 |
|----------|---------|
| PDF（含掃描件） | ✅ 完整支援，含 OCR |
| Word (DOCX) | ✅ 完整支援 |
| Excel (XLSX) | ✅ 完整支援 |
| PowerPoint (PPTX) | ✅ 完整支援 |
| 圖片 | ✅ OCR 支援 |
| 網頁 | ✅ 支援 |
| 結構化數據 | ✅ 支援 |

### 2. 🍱 模板化文本切片（Template-based Chunking）

- **智能且可解釋**：不僅是智能，更重要的是可控可解釋
- **多種模板選擇**：提供豐富的切片模板供開發者選擇
- **可視化文本切片**：讓使用者可以直觀地查看和理解文本被如何切分
- **手動干預支持**：允許使用者對自動切片結果進行手動調整
- **精確引用溯源**：支持追溯答案來源的具體文本片段

### 3. 🌱 減少幻覺的有根據引用

- **文本切片可視化**：允許人類干預切片過程
- **快速查看關鍵引用**：答案提供關鍵引用的快照
- **可追溯引用**：支持追根溯源，驗證答案的準確性
- **「Quality in, quality out」**：通過高質量的文檔處理減少錯誤輸出的傳播

### 5. 🛀 自動化 RAG 工作流

- **流暢的 RAG 協調**：適配個人和大型企業的各類生態系統
- **可配置 LLM**：支援多種大模型提供商
- **可配置 Embedding 模型**：靈活選擇向量模型
- **多路召回 + 融合重排序**：提高檢索準確性
- **易用的 API**：方便集成到企業系統

### 6. 🤖 Agent 智能代理

RAGFlow 提供強大的 Agent 能力：

- **可編程的 Agent 工作流**：通過 DSL 定義複雜的代理工作流
- **預置 Agent 模板**：提供多種場景的 Agent 模板
- **記憶功能（Memory）**：支持 AI Agent 的長期記憶（2025-12）
- **代碼執行器**：支援 Python/JavaScript 代碼執行（2025-05）
- **沙箱環境**：安全的代碼執行環境
- **插件系統**：可扩展的插件架構

### 7. 🔌 MCP 協議支援

## 總結

RAGFlow 是一款功能完備、持續迭代的開源 RAG 引擎。其核心優勢包括：

- **DeepDoc 深度文檔理解**：業界領先的非結構化數據解析能力
- **模板化文本切片**：智能且可控可解釋的切片方案
- **Agent 能力**：內建可編程的 Agent 工作流和記憶功能
- **MCP 協議**：原生支援 Model Context Protocol
- **多渠道整合**：支持多種聊天渠道整合
- **開源 Apache 2.0**：允許商業使用

適合需要構建企業級知識庫、智能客服、文檔問答等場景的開發者和企業團隊。
